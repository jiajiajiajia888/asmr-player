# asmr播放器 1.7.1

1.7.1：在“环绕效果”中增加“左右交替”，默认每0.20秒换一侧，左0.20秒加右0.20秒为一轮0.40秒。可调0.05～2.00秒，每档0.01秒，独立保存速度，一键默认恢复0.20秒。与原左右环绕和耳机环绕互斥，其他数值保留；升级不会自动开启。新效果先合并两侧声音再只送到当前一耳，显式声道复制仍按所选声道取样，自动补全模式先补全再合并。切换边缘约2毫秒淡出和淡入，稳定交替时两耳不重叠输出；效果启停和参数变化仍沿用原20毫秒过渡。播放与导出共用处理链。采样级静音、间隔、幅度、边缘连续性和旧音效检查通过，真实安卓播放及导出尚未验证。

1.7：移除抖音分享链接接收、解析、在线播放及下载功能。在线页仅支持B站；旧抖音记录保留并标记不再支持，菜单不提供播放、下载或下一首操作，清单播放全部和在线播放队列跳过旧抖音记录。本地导入的音视频不受影响。抖音专用三个源文件留在工作区但从编译和交付源码中排除，没有删除本地文件；移除专用WebKit构建依赖，安装包DEX不含专用解析类及WebKit。其余界面、声音效果和播放模式沿用已确认实现。以下段落为历史版本记录。

1.6.5：针对1.6.4手机反馈中的详情重请求返回HTML错误，删除详情重复请求，改用AndroidX WebKit的页面启动前脚本接口，在loadUrl前注册正常响应观察。新增免费官方构建依赖androidx.webkit:webkit:1.14.0，先检测系统WebView支持DOCUMENT_START_SCRIPT再调用；不支持时给出明确提示。时序回归场景中旧版首次响应漏捕、重复请求得到HTML并报相同JSON错误，新版只接收首次正常响应并取得地址。生产脚本在真实桌面浏览器中的原作品媒体访问检查通过；仍未连接真实安卓设备，尚不能证明手机端问题全部修复。其他功能保持1.6.4的实现。

1.6.4：仅调整抖音备用识别。新增读取公开网页正常详情响应的脚本，校验作品编号，从play_addr_h264或play_addr取得完整视频候选；排除浏览器内部blob地址、分离音频／画面流及常见分段格式。为备用网页设置布局尺寸，允许静音触发当前视频加载。失败提示包含详情读取状态与视频元素信息。原样例在本机真实浏览器中通过生产脚本取得完整MP4候选，两个候选用播放器请求头返回HTTP206，前64KiB含ftyp、vide和soun标识；未在真实安卓WebView与vivo手机验证，不能视为手机端或全部抖音链接已修复。未修改播放队列和声音算法。

1.6.3：播放列表改为圆角卡片，显示当前播放项，普通队列和优先下一首均提供上移／下移按钮。播放页增加明确的播放模式和播放列表文字按钮；音乐、视频、在线、清单页底部播放栏增加模式和播放列表入口。支持顺序播放、单曲循环、列表循环、随机播放。移动条目不重新加载正在播放的文件，点队列卡片可切歌。调整的是当前服务持有的播放队列，不修改媒体库或清单保存顺序；服务结束后不保证保留手动顺序。抖音解析沿用1.6.2，用户已反馈仍无法解析，本版未修复。

1.6.2：音乐、视频、在线与清单统一圆角卡片，清单主页、收藏详情及空状态重新布局，三个点使用统一图标按钮。信息显示源文件URI或原分享地址，可选择和复制。环绕幅度0～300%，新增一键默认；首次升级应用循环4.5秒、幅度200%、空间距离50%，之后保存自定义值。200～300%增加左右轨迹极端位置停留，并在耳机环绕中增加两耳电平差，不表示真实距离。抖音静态页面没有地址时，增加系统WebView公开页面加载的备用识别；返回地址必须通过MP4文件头检查。未在安卓设备上验证该备用通道，用户样例的普通请求仍未提供播放地址，不承诺已修复抖音在线播放。

1.6.1：自动补全不再压缩正常声道接近满幅的峰值，只在补入信号超出余量时限制补入部分；居中使用能量补偿和反相回退，避免单耳减半与完全反相抵消。左右环绕和耳机环绕合并为“环绕效果”的互斥选项，效果调节新增空间距离0～100%，默认45%。使用13～59毫秒的短时反射改变直达声与反射声比例，距离不是实际米数，效果需耳机试听。关闭环绕或距离0时不加入空间反射。播放和导出共用声音处理器。原立体声居中必然改变声道空间，不承诺所有细节保持不变。抖音解析未在本版修改。

1.6.0：新增播放队列、顺序播放、列表循环、单曲循环、随机播放，以及收藏和自建清单。播放页快退、快进之间的列表图标可展开当前队列；条目菜单可设为下一首播放。清单只记录文件或分享链接引用，不复制媒体。音乐、视频和在线条目均可收藏或加入清单；默认收藏清单不可删除。队列由后台播放服务持有，界面重建接管当前曲目，定时到期会取消队列在线解析。在线解析与声音算法沿用1.5.0，本阶段尚未修复抖音样例或调整环绕、声道音质。

功能：本地音视频播放、暂停、进度条、10秒/30秒/1分钟快进快退；实时声道复制、单声道转双声道、左右循环移动，周期0.1～10秒，每档0.1秒，幅度0～200%；处理后保存音频M4A或视频MP4。

通过系统文件选择器读取文件，不申请整个存储空间的读取权限，不修改原文件。音乐、视频音轨由独立媒体服务播放，返回桌面、切换应用或锁屏继续播放；返回界面重新接入视频画面。音乐与视频列表只保存源文件URI和名称，多选导入不复制媒体。定时支持30分钟、60分钟和自定义0～1440分钟（不含0），到时暂停并保留界面。

左右移动在原立体声模式中保留两声道差异，避免反相抵消；居中模式合并声道。单耳素材可先复制到另一耳再移动。输入单声道自动输出双声道。设置即时用于播放，导出则固定开始处理时的参数。

导出使用AAC，目标256千比特每秒；视频编码工厂禁止重新编码画面，只允许直接复制。不能复制到MP4的画面将提示失败。默认名称保留原文件名并加“改-”前缀，必要时追加实际容器后缀，例如改-雨声.mp3.m4a。

处理完成后才打开系统保存位置选择器；保存失败可以重试。已完成缓存路径与名称持久记录，应用重建后可恢复。应用缓存仅复用一份asmr-processing.mp4，不删除原文件或用户保存结果。下一次处理会替换上一份缓存。

开发环境：Java 17、Gradle 8.13、Android SDK 36、Build-Tools 36.0.0。官方开源AndroidX Media3 1.11.1的ExoPlayer、Transformer、Session及配套模块，采用Apache-2.0许可。

1.5.0：新增分享接收及在线页，可识别B站和抖音分享链接，在线播放、仅保存链接、下载视频到用户选择的位置。在线记录仅存分享链接、名称和平台，不存媒体文件或短效CDN地址；下载后加入本地视频列表。下载任务在系统保存位置选择器期间遇到Activity重建时，会凭已保存的分享链接重新解析。下载进行时需保持应用打开。

在线解析只支持公开页面能提供的单文件渐进式MP4。B站一条公开样例已取得元数据和媒体文件头；抖音测试页未提供可直接播放的媒体地址，故不承诺所有平台链接都能在线播放或下载。无需账户登录，不读取Cookie，不绕过付费或权限限制。在线声音经现有播放器处理链输出，退出视频页面后可后台播放。在线内容需下载后才可使用本地处理导出功能。

本机构建：在源码目录用PowerShell执行 `./构建.ps1`。构建脚本通过已有的 E:\codex 开发工具执行。若移动到其他电脑，请调整脚本和 local.properties 中的工具路径。

输出：app/build/outputs/apk/debug/app-debug.apk。交付版本为本地调试签名安装包，可覆盖同签名的0.1.0版本。

检查：checks/SeekMathCheck.java验证17项跳转逻辑；checks/SoundEngineCheck.java验证915项声音计算，并可生成20秒左右移动WAV测试音。checks/SleepDeadlineCheck.java验证49项定时计算。尚未进行手机端安装、界面、后台播放、听感和导出实测。

界面按确认的深灰与浅绿草图重排；中央播放暂停、左侧快退、右侧快进，方向图标下的10/30/60为秒数（60秒为1分钟）。声道与左右移动设置在底部弹出面板，音乐和视频页保留迷你播放器。视频预览右下角可进入横屏全屏，点击画面显示或隐藏退出入口，返回键先退出全屏。Android13以上使用原生返回回调，低版本保留旧返回处理。画面按原比例完整显示，不拉伸或裁切。VideoFitCheck验证308项画面比例计算。

1.3.0：循环默认3秒，幅度默认100%，首次升级一次性应用新默认值，后续保留自定义值。可独立开启耳机环绕，按左→前→右→后→左旋转；使用MIT KEMAR真实双耳响应，作者与许可见环绕数据来源与许可.md。环绕优先于左右摆动。200%加强两侧分离和环绕强度，不表示超出耳朵的物理定位范围。

全屏移除播放和跳转按钮，右滑快进、左滑快退，显示预览时间，松手提交；单击显示退出入口，双击播放暂停。普通页改方向图标＋时间文字，取消默认按钮阴影。SpatialCheck验证环绕响应和滑动边界，9625项检查。此前手机单声道开关造成移动感消失，用户关闭系统单声道后已确认恢复。


1.3.1：纯图标使用CenteredIconButton独立居中绘制，播放圆形固定52dp，播放图标24dp、跳转图标18dp。定时停止置于四张设置卡片首位，卡片间距统一8dp。列表元数据只在列表可见区域按单任务读取，缩略图内存缓存上限8MiB；切入播放页不再批量读取隐藏条目。名称查询在独立后台线程执行，播放先准备，名称解析前暂不能导出，防止错误文件名。

本地启动／跳转缓冲门槛150毫秒，重新缓冲350毫秒，前向最多10秒，保留15秒后向数据；这些数值是缓冲媒体时长，不是实际打开文件的耗时。跳转允许前后250毫秒内的同步点，找不到则按请求位置定位。快速连续点击60毫秒内合并，累加档位，不需等待上一跳转结束。手机实际速度未实测。


1.4.0：声道处理新增“自动声道补全”。默认检测阈值−45分贝（相对数字满刻度的均方根电平），可调−70～−20分贝。20毫秒有限窗口、60毫秒稳定确认、15毫秒渐变时间常数；安静声道低于阈值、两边相差12分贝以上且源高于−80分贝时触发，解除使用8分贝及阈值+3分贝滞回。先检测原始输入并补全，再应用空间处理，避免检测自己制造的声道变化。输入突然换耳时保护新有声边。原有四种模式不变。

自动模式同时开启环绕时保留两虚拟声源间距，避免正常反相立体声相消。播放和导出均使用同一SoundProcessor和不可变参数快照。自动补全计算147141项断言通过，实际SoundProcessor双声道PCM探针96000项断言通过，未包含手机音频输出实测。


1.4.1：检测阈值显示0～70分贝，默认30；内部映射为相对数字满刻度的负电平，显示数值越大越严格。首次升级一次性设置30，后续保留自定义值。检测窗口改为10毫秒、确认18毫秒、渐变时间常数12毫秒。自动补全不再逐样本比较绝对值并硬切换，而是保留原声，平滑补入另一声道。自动模式接近满幅时使用连续软峰值保护，避免新增叠加直接过载。旧模式不经过该处理。

连续音＋单侧弱声测试复现旧版最大采样突变0.017815，超过正常波形界限；修后0.005891并通过。合成输入80毫秒响应和过载边界检查通过，真实SoundProcessor交替声道PCM检查96000项通过。该证据不等于真机全部卡顿和爆音已消除。
