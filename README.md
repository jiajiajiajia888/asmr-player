# asmr播放器

面向助眠音频收听需求的安卓播放器。支持本地音乐、视频播放和实时声道处理，也可以将处理结果保存为新文件。

当前版本：1.7.1。最低Android 8.0，编译和目标平台Android 16。项目处于早期维护阶段，由实际收听需求逐步迭代，使用Codex辅助开发。

## 功能

- 导入音乐和视频时仅保存系统文件引用，不复制原媒体；支持后台播放、定时停止和视频全屏手势跳转。
- 快进、快退10秒、30秒和1分钟；顺序播放、列表循环、单曲循环、随机播放，支持收藏、自建清单和调整当前队列。
- 保留原声道、左声道复制到右、右声道复制到左、声道居中、自动声道补全。
- 左右环绕、耳机环绕、左右交替三种互斥效果；播放中可调整参数。
- 左右交替默认每侧0.20秒，完整一轮0.40秒；每侧可调0.05～2.00秒，步长0.01秒。
- 空间效果默认循环4.5秒、移动幅度200%、空间距离50%，移动幅度上限300%；这些参数不代表实际物理距离。
- 保存处理后的音频为M4A，视频为MP4；视频仅处理音轨，画面尽可能直接复制，不支持复制的编码会提示失败。默认输出名增加“改-”前缀。
- 支持保存B站公开普通视频链接；在线播放与下载依赖平台能否提供可访问的单文件地址，不保证所有链接可用。

**当前不支持抖音链接解析、直播接入或接管其他应用的声音。** 不绕过登录、付费、验证码或平台权限。请只处理自己有权使用的内容。

## 构建

安装Java 17和Android SDK，准备Android SDK Platform 36与Build-Tools 36.0.0。设置`ANDROID_HOME`，或在项目根目录创建仅保留在本机的`local.properties`配置`sdk.dir`。使用Android Studio也可以导入项目并配置SDK。

Windows PowerShell：

```powershell
.\gradlew.bat assembleDebug lintDebug
```

Linux或macOS：

```sh
sh ./gradlew assembleDebug lintDebug
```

首次构建需要网络下载Gradle及Maven依赖。安装包位于`app/build/outputs/apk/debug/app-debug.apk`。调试构建使用构建者自己的调试签名，**不保证可以覆盖他人生成的安装包**。

## 音频逻辑检查

Windows运行`./检查音频.ps1`；需要Java 17。它在独立的`build`子目录编译纯Java计算代码，验证交替静音、边界平滑、旧声音算法、空间响应、跳转和定时数学逻辑。完整应用构建及静态检查仍使用上述Gradle命令。其余历史检查保留供参考，不代表均由这个入口执行。

代码检查不能替代真实手机测试。现有记录见[1.7.1检查记录](docs/1.7.1检查记录.md)。实际安装、后台播放、蓝牙兼容、主观听感和编码导出仍需持续验证；没有连接手机的检查不能据此宣称完成真机验收。
